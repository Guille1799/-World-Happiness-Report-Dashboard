### What is inside

One sheet, `Data for Figure 2.1 (2011–2025)`: **2,116 rows, 168 countries, 2011–2025**. Each row is
one country-year with the three-year average life evaluation (Cantril ladder), its 95 % confidence
interval, and the contributions of the six explanatory factors.

### Attribution

The World Happiness Report is published by the Wellbeing Research Centre at the University of Oxford,
in partnership with Gallup, the UN Sustainable Development Solutions Network and an independent
editorial board. The underlying survey data come from the Gallup World Poll.

Cite the report, not this repository, for any figure taken from this file.

### On redistribution

The World Happiness Report states that the Figure 2.1 data are *"available to download for free"*
(https://www.worldhappiness.report/data-sharing/). As of the download date the site published no
licence, no terms-of-use page and no copyright notice covering the file, so **there is no written
permission to redistribute it** — the copy here is included for reproducibility and is credited
above. If the World Happiness Report asks for it to be removed, remove it: the app also knows how to
download the file at runtime, so the dashboard keeps working without it.

### How to refresh it

Delete the file and start the app. It downloads the current version from the URL above into this
folder. Then update the date, size and hash in this table — a copy with a stale hash and a fresh date
is worse than no record at all.

## `demo_whr.csv`

**Synthetic. Not real data.** Generated by `scripts/generate_demo_whr.py` with `SEED = 42`: 39
countries, 2010–2023, 546 rows. Only the GDP–life-evaluation pairing is hand-set; the other five
factors are drawn independently, so **correlations computed on this file are meaningless and some
carry the wrong sign**.

It exists so the app still starts when the real workbook is missing. When the app falls back to it,
it says so on screen.
